# Kindora – Transparent Digital Charity Platform

Kindora is a full-stack digital charity platform designed to connect donors with verified causes through transparency, real-time tracking, and secure transactions.

## Tech Stack
- Flutter (Dart) – Mobile App
- React (TypeScript) – Admin Dashboard
- Node.js (TypeScript) – Backend API
- PostgreSQL (Supabase) – Database & Authentication
- Firebase Cloud Messaging – Push Notifications
