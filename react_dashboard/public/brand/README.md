# Kindora logo (admin web)

Add **one file**:

- **`logo.png`** — put your PNG here (any reasonable size; wide logos work best under ~240px width).

That’s it. The app uses **`/brand/logo.png`** everywhere (login, header, favicon).

If `logo.png` is missing, a built-in **`logo.svg`** placeholder is shown until you add your PNG.

After replacing the file, hard-refresh the browser (`Ctrl+Shift+R`).
