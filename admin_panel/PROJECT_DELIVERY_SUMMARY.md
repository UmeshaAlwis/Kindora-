## 🚀 Quick Start Recap

### 1. Install
```bash
cd admin_panel
npm install
```

### 2. Configure
Update `src/supabaseClient.js` with your Supabase credentials

### 3. Run
```bash
npm start
```

### 4. Build
```bash
npm run build
```

### 5. Deploy
```bash
vercel    # Vercel
# or
netlify   # Netlify
```
